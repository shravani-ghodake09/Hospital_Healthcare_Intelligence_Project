# Hospital Healthcare Intelligence Dashboard

## Project Overview

The Hospital Healthcare Intelligence Dashboard is a data analytics project designed to transform hospital patient and billing data into meaningful healthcare insights.

The dashboard analyzes patient admissions, departments, diagnoses, treatments, length of stay, billing amounts, insurance usage, payment methods, patient ratings, and patient outcomes.

## Objectives

* Analyze hospital patient admissions
* Identify department-wise patient distribution
* Analyze common diagnoses
* Compare emergency and OPD patients
* Analyze hospital billing and revenue
* Study average length of stay
* Analyze insurance usage
* Understand payment preferences
* Evaluate patient satisfaction
* Analyze patient outcomes
* Provide data-driven healthcare insights

## Dataset

The project uses a synthetic hospital dataset containing 1,000 patient records.

### Main Fields
